    Úložiště a záloha

    Data se ukládají do soukromého repozitáře na GitHubu. Na každém zařízení se připojíš jednou.

    Rozšířené
    Jak token vytvořit
    1. Na GitHubu založ soukromý (Private) repozitář, třeba stickies-data. Zaškrtni „Add a README file“, ať v repozitáři něco je.
    2. Otevři Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
    3. Repository access: Only select repositories → vyber jen ten datový repozitář.
    4. Permissions → Repository → Contents: Read and write.
    5. Token zkopíruj a vlož sem. GitHub ho ukáže jen jednou.

    Odpojení smaže z tohoto zařízení token. Data v repozitáři i lokální kopie zůstávají.

    Záloha

    Načtená záloha se sloučí s tím, co už tu je. Nic se nepřepíše naslepo.
